# HANDOVER

## The status
The current status of the project is that the site includes the following:
- Homepage
- District pages with a filter system and custom styling
- Detail pages with extensive articles and a progress bar
- Newsletter
- Database

## Working features
The following features are working and visible on the website:
- Filter system
- Accessibility menu
- Dark and light mode
- Hamburger menu
- Different color themes for each neighborhood
- Progress bar
- Newsletter

## Challenges
The biggest concerns and challenges lie in the following:
### Colors for each neighborhood
Each neighborhood has its own colors, which are assigned to different elements in different ways. Some work through URL routing, others purely through CSS.

### Overview of the small article component
This uses container queries. The challenge here lies with the design and the length of the titles. Some titles are very long, stretching the cards, resulting in the cards with short titles not being perfectly proportionate.
