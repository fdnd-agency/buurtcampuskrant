- Responsive design zorgt voor een goede weergave op verschillende schermen.
- Lighthouse helpt bij het verbeteren van mijn website.
- GitHub Issues helpen mij mijn werkzaamheden te organiseren.

### Wat neem ik mee?
Ik wil mijn kennis van SvelteKit, Directus, toegankelijkheid en het oplossen van technische problemen verder ontwikkelen.

### Wat heb ik geleerd?
Ik heb geleerd hoe ik met Svelte `$props()` gebruik om gegevens door te geven aan een component. Ook heb ik geleerd hoe ik semantische HTML gebruik.
